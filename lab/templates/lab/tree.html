📖 What is a Tree?

A Tree is a non-linear data structure that represents hierarchical relationships between elements.

A tree consists of nodes connected by edges. The first node is called the root node.

🧩 Tree Terminology

  • Node: An element of a tree.
  • Root: The topmost node of a tree.
  • Parent: A node that has one or more children.
  • Child: A node directly connected below another node.
  • Leaf: A node having no children.
  • Edge: The connection between two nodes.
  • Height: The number of edges on the longest path from a node to a leaf.
  • Depth: The number of edges from the root to a particular node.

🔍 Binary Search Tree

A Binary Search Tree (BST) is a binary tree in which the left subtree contains values smaller than the root and the right subtree contains values greater than the root.

BST Properties

  • Each node can have at most two children.
  • Values in the left subtree are smaller than the node value.
  • Values in the right subtree are greater than the node value.
  • Duplicate handling depends on the implementation.

Example

        50
       /  \
     30    70
    / \    / \
   20 40  60 80

BST Operations

  • Insertion
  • Deletion
  • Searching
  • Traversal

Time Complexity

Operation Average Worst
Search O(log n) O(n)
Insertion O(log n) O(n)
Deletion O(log n) O(n)

🔄 Tree Traversal

Tree traversal is the process of visiting every node of a tree exactly once.

1. Preorder Traversal

In Preorder traversal, the root node is visited first, followed by the left subtree and then the right subtree.

Root → Left → Right

2. Inorder Traversal

In Inorder traversal, the left subtree is visited first, followed by the root and then the right subtree.

Left → Root → Right

In a Binary Search Tree, Inorder traversal produces the elements in sorted order.

3. Postorder Traversal

In Postorder traversal, the left subtree is visited first, followed by the right subtree and then the root.

Left → Right → Root

Traversal Example

        1
       / \
      2   3
     / \
    4   5
Traversal Order
Preorder Root → Left → Right
Inorder Left → Root → Right
Postorder Left → Right → Root

🌳 B Tree

A B Tree is a self-balancing multi-way search tree in which each node can contain multiple keys and multiple children.

Properties

  • A node can contain multiple keys.
  • A node can have multiple children.
  • All leaf nodes are at the same level.
  • B Trees remain balanced after insertion and deletion.
  • They are useful for storing large amounts of data.

Applications

  • Database indexing
  • File systems
  • Disk-based storage

Example

20 | 40
5 | 10 | 15
25 | 30
45 | 50 | 60

🌿 B+ Tree

A B+ Tree is a balanced multi-way tree commonly used in databases and file systems. Unlike a B Tree, actual records are stored at the leaf level.

Properties

  • Internal nodes contain search keys.
  • Actual data records are stored at leaf nodes.
  • Leaf nodes are linked together.
  • All leaves are at the same level.
  • Sequential access is efficient.

Advantages

  • Efficient range searching.
  • Efficient sequential traversal.
  • Suitable for database indexing.

Example

30 | 60
10 | 20
30 | 40 | 50
60 | 70 | 80
