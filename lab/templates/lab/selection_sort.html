🎯 Selection Sort

Learn the complete concept, working, algorithm, complexity and C implementation of Selection Sort.

📖 What is Selection Sort?

Selection Sort is a comparison-based sorting algorithm. It repeatedly selects the smallest element from the unsorted portion of the array and places it at the beginning of that portion.

In ascending order, the smallest element is selected in every pass and moved to its correct position.

⚙️ How Selection Sort Works

  1. Start from the first element.
  2. Assume the first unsorted element is the minimum.
  3. Compare it with all remaining unsorted elements.
  4. Find the smallest element.
  5. Swap the smallest element with the first element of the unsorted portion.
  6. Move to the next position and repeat.
  7. Continue until the complete array is sorted.

🧩 Example

Consider the following array:

40   10   30   20

Pass 1

The smallest element is 10. Swap 10 with 40.

10   40   30   20

Pass 2

From the remaining elements, the smallest is 20.

10   20   30   40

Pass 3

The remaining elements are already in the correct order.

10   20   30   40

📝 Selection Sort Algorithm 

SelectionSort(array, n)

    for i = 0 to n - 2

        minIndex = i

        for j = i + 1 to n - 1

            if array[j] < array[minIndex]

                minIndex = j

            end if

        end for

        swap(
            array[i],
            array[minIndex]
        )

    end for

⏱ Time Complexity

Case Complexity
Best Case O(n²)
Average Case O(n²)
Worst Case O(n²)
Space Complexity O(1)

✅ Advantages

  • Easy to understand and implement.
  • Requires O(1) extra space.
  • Performs fewer swaps than Bubble Sort.
  • Suitable for small datasets.

❌ Disadvantages

  • Time complexity is O(n²).
  • Not efficient for large datasets.
  • Performs many comparisons even when the array is already sorted.

💻 C Language Implementation

Complete Selection Sort implementation using C language. 

#include <stdio.h>

void selectionSort(int arr[], int n)
{
    int i;
    int j;
    int minIndex;
    int temp;

    for(i = 0; i < n - 1; i++)
    {
        minIndex = i;

        for(j = i + 1; j < n; j++)
        {
            if(arr[j] < arr[minIndex])
            {
                minIndex = j;
            }
        }

        temp = arr[i];

        arr[i] = arr[minIndex];

        arr[minIndex] = temp;
    }
}


int main()
{
    int arr[] = {
        40, 10, 30, 20, 50
    };

    int n = 5;

    int i;


    selectionSort(arr, n);


    printf("Sorted Array: ");


    for(i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }


    return 0;
}
