📝 Insertion Sort

Learn the complete concept, working, algorithm, complexity and C implementation of Insertion Sort.

📖 What is Insertion Sort?

Insertion Sort is a simple comparison-based sorting algorithm. It builds the sorted array one element at a time.

Each new element is compared with the elements in the sorted portion and is inserted into its correct position.

⚙️ How Insertion Sort Works

  1. Start from the second element of the array.
  2. Store the current element as the key.
  3. Compare the key with the elements before it.
  4. Shift elements greater than the key one position to the right.
  5. Insert the key into its correct position.
  6. Repeat until the complete array is sorted.

🧩 Example

Consider the following array:

40   20   30   10

Pass 1

Key = 20. Compare 20 with 40 and shift 40.

20   40   30   10

Pass 2

Key = 30. Shift 40 and insert 30.

20   30   40   10

Pass 3

Key = 10. Shift 40, 30 and 20 and insert 10.

10   20   30   40

📝 Insertion Sort Algorithm

InsertionSort(array, n)

    for i = 1 to n - 1

        key = array[i]

        j = i - 1

        while j >= 0
              and array[j] > key

            array[j + 1] = array[j]

            j = j - 1

        end while

        array[j + 1] = key

    end for

💡 Pseudocode

for i = 1 to n-1

    key = A[i]

    j = i-1

    while j >= 0 AND A[j] > key

        A[j+1] = A[j]

        j = j-1

    end while

    A[j+1] = key

end for

⏱ Time Complexity

Case Complexity
Best Case O(n)
Average Case O(n²)
Worst Case O(n²)
Space Complexity O(1)

✅ Advantages

  • Simple and easy to implement.
  • Requires O(1) extra space.
  • Efficient for small datasets.
  • Efficient when the array is already nearly sorted.
  • Stable sorting algorithm.

❌ Disadvantages

  • O(n²) average and worst-case time.
  • Not suitable for large datasets.
  • Requires many shifts for reverse-sorted arrays.

💻 C Language Implementation

Complete Insertion Sort implementation using C language. 

#include <stdio.h>

void insertionSort(int arr[], int n)
{
    int i;
    int j;
    int key;

    for(i = 1; i < n; i++)
    {
        key = arr[i];

        j = i - 1;

        while(
            j >= 0 &&
            arr[j] > key
        )
        {
            arr[j + 1] = arr[j];

            j--;
        }

        arr[j + 1] = key;
    }
}


int main()
{
    int arr[] = {
        40, 20, 30, 10, 50
    };

    int n = 5;

    int i;


    insertionSort(arr, n);


    printf("Sorted Array: ");


    for(i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }


    return 0;
}
