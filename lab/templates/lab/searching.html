📖 What is Searching?

Searching is the process of finding a particular element or value from a collection of data.

The value that we want to find is called the search key.

Example: If an array contains 10, 20, 30, 40, 50 and we want to find 30, then 30 is the search key.

🔎 Linear Search

Linear Search checks every element one by one from the beginning of the array until the required element is found or the array ends.

How Linear Search Works

  1. Start from the first element.
  2. Compare the current element with the search key.
  3. If both are equal, the element is found.
  4. Otherwise move to the next element.
  5. Continue until the element is found or the array ends.

Linear Search Algorithm 

LinearSearch(array, n, key)

1. Start from index 0
2. Compare array[i] with key
3. If array[i] == key
       return i
4. Otherwise continue
5. If element is not found
       return -1

⚡ Binary Search

Binary Search is an efficient searching technique that works on a sorted array.

It repeatedly divides the search range into two halves and eliminates the half that cannot contain the required element.

How Binary Search Works

  1. The array must be sorted.
  2. Find the middle element.
  3. Compare the middle element with the search key.
  4. If equal, the element is found.
  5. If the key is smaller, search the left half.
  6. If the key is larger, search the right half.

Binary Search Algorithm 

BinarySearch(array, n, key)

1. low = 0
2. high = n - 1

3. while low <= high

       mid = (low + high) / 2

       if array[mid] == key
           return mid

       else if key < array[mid]
           high = mid - 1

       else
           low = mid + 1

4. return -1

⚖️ Linear Search vs Binary Search

Feature Linear Search Binary Search
Data Requirement Sorted or Unsorted Sorted
Technique Sequential Divide and Conquer
Best Case O(1) O(1)
Average Case O(n) O(log n)
Worst Case O(n) O(log n)

📱 Applications of Searching

  • Finding records in databases.
  • Searching names in contact lists.
  • Finding products in an online store.
  • Searching files in a computer.
  • Finding values in arrays and data structures.
  • Information retrieval systems.

💻 C Language Implementation

Below is the C implementation of both Linear Search and Binary Search.

Linear Search 
#include <stdio.h>

int linearSearch(
    int arr[],
    int n,
    int key
)
{
    for (int i = 0; i < n; i++)
    {
        if (arr[i] == key)
        {
            return i;
        }
    }

    return -1;
}

int main()
{
    int arr[] = {
        10, 20, 30, 40, 50
    };

    int n = 5;

    int key = 30;

    int result =
        linearSearch(arr, n, key);

    if (result != -1)
    {
        printf(
            "Element found at position %d",
            result + 1
        );
    }
    else
    {
        printf("Element not found");
    }

    return 0;
}
Binary Search 
#include <stdio.h>

int binarySearch(
    int arr[],
    int n,
    int key
)
{
    int low = 0;

    int high = n - 1;

    while (low <= high)
    {
        int mid =
            (low + high) / 2;

        if (arr[mid] == key)
        {
            return mid;
        }

        else if (key < arr[mid])
        {
            high = mid - 1;
        }

        else
        {
            low = mid + 1;
        }
    }

    return -1;
}

int main()
{
    int arr[] = {
        10, 20, 30, 40, 50
    };

    int n = 5;

    int key = 40;

    int result =
        binarySearch(arr, n, key);

    if (result != -1)
    {
        printf(
            "Element found at position %d",
            result + 1
        );
    }
    else
    {
        printf("Element not found");
    }

    return 0;
}
