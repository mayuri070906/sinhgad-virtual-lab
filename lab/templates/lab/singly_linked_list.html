📖 What is Singly Linked List?

A Singly Linked List is a linear data structure in which elements are stored in nodes. Each node contains two parts: data and a pointer to the next node.

Unlike an array, linked list elements are not stored in contiguous memory locations. Each node points to the next node using a pointer.

Key Idea: Data + Address of Next Node

🧩 Structure of Singly Linked List

A node in a singly linked list contains:

  • Data: Stores the actual value.
  • Next: Stores the address of the next node.

struct Node

⚙️ Operations

The following operations can be performed on a Singly Linked List:

1 Begin Insert

Insert a new node at the beginning.

2 End Insert

Insert a new node at the end.

3 Location Insert

Insert a node at a specific position.

4 Begin Delete

Delete the first node.

5 End Delete

Delete the last node.

6 Location Delete

Delete a node from a specific position.

7 Search

Search for a particular value.

✅ Advantages

  • Dynamic size.
  • Efficient insertion and deletion.
  • Memory is allocated dynamically.
  • Does not require contiguous memory.
  • Easy to grow and shrink during runtime.

❌ Disadvantages

  • Extra memory is required for storing pointers.
  • Random access is not possible.
  • Searching takes O(n) time.
  • Traversal is possible only in forward direction.
  • Pointer manipulation is required.

📱 Applications

  • Implementation of stacks.
  • Implementation of queues.
  • Dynamic memory management.
  • Graph representation.
  • Hash table chaining.
  • Polynomial representation.

⏱ Time Complexity

💻 C Language Implementation

Complete implementation of Singly Linked List using C language. 

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *head = NULL;


/* Insert at Beginning */

void insertBegin(int value)
{
    struct Node *newNode;

    newNode =
        (struct Node*)malloc(sizeof(struct Node));

    newNode->data = value;

    newNode->next = head;

    head = newNode;
}


/* Insert at End */

void insertEnd(int value)
{
    struct Node *newNode;
    struct Node *temp;

    newNode =
        (struct Node*)malloc(sizeof(struct Node));

    newNode->data = value;

    newNode->next = NULL;

    if (head == NULL)
    {
        head = newNode;
        return;
    }

    temp = head;

    while (temp->next != NULL)
    {
        temp = temp->next;
    }

    temp->next = newNode;
}


/* Insert at Location */

void insertLocation(int value, int position)
{
    struct Node *newNode;
    struct Node *temp;

    newNode =
        (struct Node*)malloc(sizeof(struct Node));

    newNode->data = value;

    if (position == 1)
    {
        newNode->next = head;

        head = newNode;

        return;
    }

    temp = head;

    for (int i = 1;
         i < position - 1 && temp != NULL;
         i++)
    {
        temp = temp->next;
    }

    if (temp == NULL)
    {
        printf("Invalid position\n");

        free(newNode);

        return;
    }

    newNode->next = temp->next;

    temp->next = newNode;
}


/* Delete at Beginning */

void deleteBegin()
{
    struct Node *temp;

    if (head == NULL)
    {
        printf("List is empty\n");
        return;
    }

    temp = head;

    head = head->next;

    free(temp);
}


/* Delete at End */

void deleteEnd()
{
    struct Node *temp;
    struct Node *prev;

    if (head == NULL)
    {
        printf("List is empty\n");
        return;
    }

    if (head->next == NULL)
    {
        free(head);

        head = NULL;

        return;
    }

    temp = head;

    while (temp->next != NULL)
    {
        prev = temp;

        temp = temp->next;
    }

    prev->next = NULL;

    free(temp);
}


/* Delete at Location */

void deleteLocation(int position)
{
    struct Node *temp;
    struct Node *prev;

    if (head == NULL)
    {
        printf("List is empty\n");
        return;
    }

    if (position == 1)
    {
        temp = head;

        head = head->next;

        free(temp);

        return;
    }

    temp = head;

    for (int i = 1;
         i < position && temp != NULL;
         i++)
    {
        prev = temp;

        temp = temp->next;
    }

    if (temp == NULL)
    {
        printf("Invalid position\n");
        return;
    }

    prev->next = temp->next;

    free(temp);
}


/* Search */

void search(int value)
{
    struct Node *temp;

    int position = 1;

    temp = head;

    while (temp != NULL)
    {
        if (temp->data == value)
        {
            printf("Found at position %d\n",
                   position);

            return;
        }

        temp = temp->next;

        position++;
    }

    printf("Value not found\n");
}


/* Display */

void display()
{
    struct Node *temp = head;

    while (temp != NULL)
    {
        printf("%d -> ", temp->data);

        temp = temp->next;
    }

    printf("NULL\n");
}


int main()
{
    insertBegin(10);

    insertEnd(20);

    insertEnd(30);

    insertLocation(15, 2);

    display();

    search(20);

    deleteBegin();

    deleteEnd();

    deleteLocation(2);

    display();

    return 0;
}
