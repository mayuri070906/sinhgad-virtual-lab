🔀 Merge Sort

Learn the complete concept, working, algorithm, complexity and C implementation of Merge Sort.

📖 What is Merge Sort?

Merge Sort is a divide-and-conquer sorting algorithm. It divides an array into smaller subarrays, sorts them and then merges the sorted subarrays.

The array is repeatedly divided until each subarray contains only one element. These smaller arrays are then merged in sorted order.

🧠 Divide and Conquer

Merge Sort follows three main steps:

  1. Divide: Divide the array into two halves.
  2. Conquer: Recursively sort both halves.
  3. Combine: Merge the two sorted halves.

🧩 Example

Consider the following array:

40   20   30   10

Step 1 — Divide

[40 20]    [30 10]

Step 2 — Divide Again

[40] [20]    [30] [10]

Step 3 — Merge

[20 40]    [10 30]

Step 4 — Final Merge

10   20   30   40

📝 Merge Sort Algorithm

MergeSort(A, low, high)

    if low < high

        mid = (low + high) / 2

        MergeSort(A, low, mid)

        MergeSort(A, mid + 1, high)

        Merge(A, low, mid, high)

    end if

🔗 Merge Algorithm

Merge(A, low, mid, high)

    i = low

    j = mid + 1

    k = low

    while i <= mid AND j <= high

        if A[i] <= A[j]

            temp[k] = A[i]

            i++

        else

            temp[k] = A[j]

            j++

        k++

    end while


    while i <= mid

        temp[k] = A[i]

        i++

        k++

    end while


    while j <= high

        temp[k] = A[j]

        j++

        k++

    end while


    for i = low to high

        A[i] = temp[i]

    end for

⏱ Time & Space Complexity

Case Complexity
Best Case O(n log n)
Average Case O(n log n)
Worst Case O(n log n)
Space Complexity O(n)

✅ Advantages

  • Guaranteed O(n log n) time complexity.
  • Works efficiently with large datasets.
  • Stable sorting algorithm.
  • Uses divide-and-conquer technique.
  • Suitable for external sorting.

❌ Disadvantages

  • Requires additional memory.
  • Space complexity is O(n).
  • More complex than simple sorting algorithms.

💻 C Language Implementation

Complete Merge Sort implementation using C language. 

#include <stdio.h>

void merge(
    int arr[],
    int low,
    int mid,
    int high
)
{
    int temp[100];

    int i = low;

    int j = mid + 1;

    int k = low;


    while(
        i <= mid &&
        j <= high
    )
    {
        if(
            arr[i] <= arr[j]
        )
        {
            temp[k] =
                arr[i];

            i++;
        }
        else
        {
            temp[k] =
                arr[j];

            j++;
        }

        k++;
    }


    while(i <= mid)
    {
        temp[k] =
            arr[i];

        i++;

        k++;
    }


    while(j <= high)
    {
        temp[k] =
            arr[j];

        j++;

        k++;
    }


    for(
        i = low;
        i <= high;
        i++
    )
    {
        arr[i] =
            temp[i];
    }
}


void mergeSort(
    int arr[],
    int low,
    int high
)
{
    if(low < high)
    {
        int mid =
            (low + high) / 2;


        mergeSort(
            arr,
            low,
            mid
        );


        mergeSort(
            arr,
            mid + 1,
            high
        );


        merge(
            arr,
            low,
            mid,
            high
        );
    }
}


int main()
{
    int arr[] = {
        40,
        20,
        30,
        10,
        50
    };


    int n = 5;

    int i;


    mergeSort(
        arr,
        0,
        n - 1
    );


    printf(
        "Sorted Array: "
    );


    for(
        i = 0;
        i < n;
        i++
    )
    {
        printf(
            "%d ",
            arr[i]
        );
    }


    return 0;
}
